# Online Safe 视觉与交互规范 v3.1

> 视觉参考：Stripe 式金融级设计语言（深海军蓝标题、蓝调层叠阴影、克制圆角、精确排版），
> 结合本产品「个人账密保险箱」的信任诉求本地化为中文界面。
> 本文档是前端唯一视觉依据；实现与文档必须同步演进。

## 1. 设计立场

### 1.1 设计问题

Online Safe 面向需要保存多来源账号资料的个人用户与管理员；它必须在信息密度逐渐增加时，仍让用户迅速判断"我在哪里、现在能做什么、哪些内容不会被意外暴露"。

### 1.2 视觉锚点：金融级信任感

安全产品最容易犯两种错误：做成冷冰冰的"黑客终端"，或做成毫无质感的灰白表格。
本产品采用**金融机构级的精致克制**：

- **深海军蓝标题**（`#0A2540`）代替纯黑——温润、可信、像一份被认真对待的财务文件；
- **蓝调层叠阴影**代替发丝线堆砌——层级由光影表达，阴影本身带品牌蓝底色，让"浮起"的元素也在品牌氛围里；
- **单一信任蓝**（`#155EEF`）作为唯一交互强调色——按钮、链接、焦点、选中态全部由它承担；
- **克制圆角**（6–10px）——既不尖锐也不玩具化。

### 1.3 标志性设计动作：蓝调纵深

页面层级不靠边框线数量，靠**三级纵深**：页面底色（淡蓝灰 `#F6F9FC`）→ 白色卡片（带蓝调柔和阴影）→ 浮层（弹窗/菜单，带蓝调深阴影）。用户能凭光影直觉判断"哪一层正在响应我"。认证页左侧保留深海军蓝品牌区，形成明暗节奏。

### 1.4 不可妥协的边界

- 一个页面只坚持这一种视觉方向，不混入深色终端、纸张纹理、霓虹渐变、玻璃拟态或拟物装饰。
- 所有用户可见文案使用中文；`Online Safe`、API、IP 等必要技术标识可保留英文。
- 页面只展示真实业务信息或明确的操作说明；禁止假用户名、假记录数量、假安全指标、填充式副标题和主题化口号。
- 2FA 密钥及未识别用途的自定义敏感字段不得以明文出现在首页、列表、搜索建议、日志或通知中；列表可展示账号名明文与密码暗文，复制时写入剪贴板的是真实明文。

## 2. 内容与信息原则

### 2.1 用户任务优先级

| 页面 | 第一任务 | 次要任务 | 不应抢占注意力的内容 |
| --- | --- | --- | --- |
| 个人登录 | 输入账号并登录 | 切换至注册或管理员入口 | 大段安全承诺、品牌故事 |
| 注册 | 完成当前步骤 | 查看格式与验证码说明 | 未实现功能的预告 |
| 忘记密码 | 完成手机验证码验证并重置 | 返回登录 | 与当前步骤无关的说明 |
| 管理员登录 | 进入管理后台 | 返回个人用户入口 | 与个人登录重复的说明 |
| 保险箱首页 | 找到记录或新增记录 | 筛选、排序、切换视图、复制账号/密码 | 密码明文、虚构统计图 |
| 管理后台 | 管理邀请码与用户 | 检索、筛选、查看状态 | 个人保险箱内容 |

### 2.2 文案纪律

- 标准操作使用标准文案：`登录`、`注册`、`新增记录`、`保存`、`取消`、`返回`、`清除筛选`。
- 不使用"认证会话""安全操作员""智能中枢"等替代常用操作的主题化措辞。
- 无数据时说明真实状态与下一步，例如"你的保险箱还是空的""添加第一条记录"；不生成示例账号填满页面。
- 错误消息说明问题与下一步：如"账号或密码错误，请重新输入""网络连接失败，请重试"；不能以"没有访问权限"掩盖表单或网络问题。

## 3. 视觉系统

### 3.1 设计令牌

#### 颜色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 页面背景 | `#F6F9FC` | 全局背景；带轻微蓝味的浅灰，不是纯灰 |
| 表面 | `#FFFFFF` | 卡片、表单、弹层 |
| 深色品牌区 | `#0A2540` | 认证页左栏、深色区块背景 |
| 主色 / 信任蓝 | `#155EEF` | 主操作、链接、焦点、选中态（唯一强调色） |
| 主色悬停 | `#0E4FD1` | 主按钮 hover |
| 主色浅底 | `#EFF4FF` | 选中项背景、图标底、信息提示底 |
| 标题文字 | `#0A2540` | 全部标题、导航文字、强标签（深海军蓝，不用纯黑） |
| 正文文字 | `#425466` | 正文、描述（蓝灰 slate） |
| 次级文字 | `#697386` | 元信息、占位、时间戳 |
| 边框 | `#E6EBF1` | 卡片、分隔、控件静态边框（蓝味浅灰） |
| 焦点环 | `rgba(21, 94, 239, .12)` | 输入框聚焦外圈，3px 柔和光晕 |
| 输入框聚焦描边 | `#6B93F0` | 比主色更浅，保持 1px，避免高饱和粗边突兀 |
| 成功 | `#108C3D` | 成功状态文字/图标；浅底 `rgba(21,190,83,.12)` |
| 警告 | `#B54708` | 需留意状态；浅底 `#FFFAEB` |
| 错误 | `#B42318` | 失败、字段校验；浅底 `#FEF3F2` |

信任蓝是唯一品牌强调色。错误、成功和警告只在对应语义状态中使用，且必须同时具备图标或文字，不单靠颜色。

#### 阴影（蓝调层叠，核心签名）

| 层级 | 值 | 用途 |
| --- | --- | --- |
| Level 0 | 无阴影 | 页面背景、行内元素、工具区 |
| Level 1 环境 | `0 2px 5px -1px rgba(50,50,93,.12), 0 1px 3px -1px rgba(0,0,0,.08)` | 静止卡片、记录卡、统计卡 |
| Level 2 悬浮 | `0 6px 12px -2px rgba(50,50,93,.16), 0 3px 7px -3px rgba(0,0,0,.10)` | 卡片 hover、下拉菜单 |
| Level 3 浮层 | `0 13px 27px -5px rgba(50,50,93,.22), 0 8px 16px -8px rgba(0,0,0,.18)` | 弹窗、抽屉、命令面板 |

规则：阴影必须成对出现（远层蓝调 + 近层中性），不使用单层灰黑阴影；负 spread 保证阴影不横向溢出。卡片可同时保留 `1px` `#E6EBF1` 边框增强轮廓。

#### 圆角

| 元素 | 圆角 |
| --- | --- |
| 按钮、输入框、下拉 | 6px |
| 卡片、提示条 | 10px |
| 弹窗 | 12px |
| 标签（tag/chip） | 6px（不使用 999px 胶囊，除非是圆形头像/图标） |

### 3.2 字体与数字

- 字体栈：`-apple-system, "SF Pro Text", "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif`；不混入衬线或等宽展示字体。
- 中文标题不追求超细字重（Windows 渲染差）；用 **600 字重 + 深海军蓝 + 收紧字距（-0.01em ～ -0.02em）** 表达高级感。
- 层级：
  - 页面标题 28px/600（移动端 24px），深海军蓝；
  - 区块标题 18px/600；卡片标题 15px/600；
  - 正文 14px/400/行高 1.6，`#425466`；
  - 辅助 12.5px/400，`#697386`。
- 记录数量、日期、序号、页码、统计数字一律 `font-variant-numeric: tabular-nums`。
- 全部文字左对齐；空状态行动区可居中，但标题和说明本身保持左对齐。

### 3.3 按钮高度（相对旧规范整体 −10px）

| 场景 | 高度令牌 | 值 |
| --- | --- | --- |
| 工作区默认主/次按钮 | `--os-control-md` / Vuetify `VBtn` | **30px**（旧 40） |
| 小控件 / 紧凑钮 | `--os-control-sm` | **26px**（旧 36） |
| 二次确认弹窗按钮 | `os-confirm-dialog__*` | **28px** |
| 管理端表格行内操作 | `admin-row-actions__btn` | **26px**；主操作 `flat` 实心，次操作 `text`；禁止臃肿 `tonal` 色块 |
| 认证页主按钮 | `--os-control-auth` | **38px**（旧 48） |
| 手机触控命中区 | `--os-control-touch` | **40px**（保证点按，视觉可更小） |

后续新增按钮一律按上表，禁止再回到 40/48 的「偏高」默认；表格行内禁止大块 `variant="tonal"` 操作钮。

### 3.4 下拉框（紧凑规范）

| 要素 | 规范 |
| --- | --- |
| 字段 | `v-select` / `v-autocomplete` / `v-combobox`：`outlined` + `density="compact"`，字段高约 **34px**（`--os-control-field`），字号 13px |
| 选项列表 | 菜单挂 `contentClass: os-select-menu`；选项行高 **32px**（`--os-select-item`），标题 13px/500，上下内边距克制 |
| 全局默认 | `frontend/src/plugins/vuetify.ts` 已写入 `menuProps.contentClass = 'os-select-menu'` |
| 禁止 | 使用默认偏高的 Vuetify 列表项（约 48px）、放大字号或宽松 padding |

筛选栏、表单弹窗与业务页下拉一律遵循上表；需要自定义菜单时仍应挂 `os-select-menu` 或等价紧凑样式。

### 3.5 结构与动效

- 4px 间距网格，常用 8、12、16、20、24、32、48px；卡片内边距 16–20px，区块间距 24–32px。
- 层级由「背景 → 卡片 → 浮层」的阴影纵深表达；同层内部才用 1px 边框或分隔线。
- 过渡 160–220ms `ease`；hover 时卡片阴影从 Level 1 过渡到 Level 2，可伴随 1px 上移（`translateY(-1px)`）；支持 `prefers-reduced-motion` 时禁用位移。
- 不使用渐变按钮、玻璃拟态、颗粒纹理、霓虹光晕；深色品牌区可用**极低饱和的径向光斑**营造氛围（认证页左栏）。

## 4. 布局骨架

### 4.1 认证页（登录 / 注册 / 忘记密码 / 管理员登录）

- 桌面双栏：左侧深海军蓝品牌区（`#0A2540` + 低饱和蓝色径向光斑），承载品牌名、一句真实价值主张、2–3 条真实能力说明；右侧白色表单区，表单最大宽度 420px，垂直居中。
- 左栏文字：标题白色 600 字重；说明 `rgba(255,255,255,.72)`；图标底色 `rgba(255,255,255,.08)` 圆角方块。
- 表单卡片不额外套框（右栏本身是白色表面）；输入框 6px 圆角、明确标签；主按钮 **38px** 高（相对旧 48 −10）、信任蓝、全宽。
- `< 960px` 单列：品牌区收成顶部一条紧凑横幅（深海军蓝、品牌名 + 一句话），表单在自然文档流。
- 信息顺序固定：品牌与入口切换 → 页面标题与一条任务说明 → 表单 → 主操作 → 辅助跳转。

### 4.2 保险箱工作区

- 左侧固定侧栏（白色表面 + 右侧 1px 边框）：菜单项 6px 圆角，选中态 = 主色浅底 `#EFF4FF` + 信任蓝文字；不整页跳转，只切右侧内容。
- 顶栏：白色、底部 1px 边框、`backdrop-filter: blur` 可选；右侧用户菜单。
- 标题区：左侧 `我的保险箱` + 真实记录数量（tabular-nums）；右侧唯一主操作"新增记录"。
- 工具区（搜索/筛选/排序/视图切换）：同一行、紧凑控件、无卡片套壳，底部 1px 边框与记录区分隔。
- 记录卡：白色、10px 圆角、1px 边框 + Level 1 阴影；hover 升至 Level 2 并上移 1px。
- 记录卡内容：名称（15px/600/深海军蓝）、平台·渠道（12.5px 次级）、状态（右上纯文字着色，见 4.4）；中部用上下分隔线展示账号明文 + 密码暗文，复制图标紧邻数值右侧；底部左侧标签、右侧「编辑」+ 更新时间。
- 点击整张卡片进入详情；编辑与复制需阻止冒泡，不触发进详情。
- 空状态：图标 + "你的保险箱还是空的" + "添加第一条记录"按钮；不伪造示例。

### 4.3 管理后台

- 与保险箱同构：白色侧栏 + 顶栏 + 内容区。
- 统计卡：白色、Level 1 阴影、图标右置于主色浅底圆角方块；数值 24px/600/tabular-nums。
- 表格：表头 12.5px/600/次级色/大写不适用中文可省；行高紧凑、行 hover 用 `#F6F9FC` 底色；操作列右对齐。
- 管理员不应在任何界面看到个人用户的保险箱明文；权限边界由接口保证，界面只负责明确表达边界。
- 公告：管理端「公告」页维护多条草稿/发布/下线；编辑已发布公告会回到草稿，需重新发布（刷新发布时间并重置已读）；用户端强制弹窗展示最新发布且未读的一条；首页展示最新置顶公告横幅。

### 4.4 状态着色（纯文字，无底色胶囊）

记录仅三种状态：正常 / 异常 / 过期。新建默认正常且不可选手填；有效期可不填（永久有效），填写后到期自动视为过期；列表可「标记异常」（二次确认）。

| 状态 | 颜色 |
| --- | --- |
| 正常 | `#108C3D` |
| 异常 | `#C4320A` |
| 过期 | `#B54708` |

## 5. 页面交互规范

### 5.1 登录与管理员登录

- 个人登录与管理员入口使用语义化分段控件，当前项信任蓝文字 + 底部 2px 信任蓝下划线。
- 输入标签保持可见：个人登录"手机号或用户名"，管理员登录"管理员用户名"，密码"登录密码"。
- 提交失败提示位于标题与第一个输入框之间；字段错误位于对应字段下方；提交时聚焦第一个错误字段。
- 登录中主按钮显示"正在登录"，禁用重复提交和入口切换。
- 密码可见性按钮必须有中文 `aria-label`。

### 5.2 注册与手机验证码

注册两步流程，始终保留进度与返回路径：**验证手机号 → 设置密码**。

- 步骤指示：当前步信任蓝、已完成步打勾、未到步次级色。
- 获取验证码按钮带倒计时（默认 60 秒），防止连点；短信失败提示位于表单顶部。
- 注册开放：不要求邀请码；管理端仍保留邀请码管理能力（当前不参与注册校验）。
- 忘记密码改为：输入已注册手机号 → 短信验证码 → 设置新登录密码；不再提供密保问题。
- 成功后短暂过渡"注册成功，正在进入保险箱"。

### 5.3 保险箱检索与记录操作

- 搜索范围仅限当前用户本地已解密记录；搜索框说明可搜名称、平台或标签。
- 筛选存在时显示"清除筛选"；无结果时说明"没有符合当前条件的记录"并保留清除入口。
- 页面状态严格区分为加载、加载失败、真正空库、筛选无结果、正常数据；不得在加载或失败时误报"保险箱为空"。
- 记录标题是进入详情的明确入口；编辑、复制是并列原生按钮，禁止把含内部按钮的整张卡模拟为一个按钮。
- 复制成功反馈"已复制 + 字段名"，不回显字段值。
- 新建/编辑走弹窗（Level 3 阴影、12px 圆角、内容区可滚、底部固定取消/保存）。
- **表单弹窗一律**对齐「记录新增/编辑」规范：紧凑控件（约 34px 高）、分区色标 + 字段类型色条，入场/hover 微动效；实现类名 `os-form-dialog*`（见 `frontend/src/styles/main.scss`）。禁止再做宽松白底、无分区色的大控件录入弹窗。
- **二次确认弹窗一律**使用统一组件 `OsConfirmDialog`（类名 `os-confirm-dialog*`）：删除/危险操作用 `danger`，警告类用 `warning`，普通确认用 `primary`。禁止再用浏览器 `window.confirm` 或无图标的纯文字小白框。

### 5.3.1 统一二次确认弹窗（强制）

适用：删除模板/记录/邀请码、标记异常、禁用用户、使会话失效等一切「不可轻易撤销」的操作。

| 要素 | 规范 |
| --- | --- |
| 组件 | `frontend/src/components/OsConfirmDialog.vue` |
| 样式 | `frontend/src/styles/main.scss` 中 `os-confirm-dialog*` |
| 遮罩 | 深海军蓝半透明 + 轻微 blur（`prefers-reduced-motion` 时关闭 blur） |
| 卡片 | 白底、12px 圆角、L3 阴影、顶部语义色光晕 |
| 图标区 | 40px 圆角方块；danger 用错误浅红底 + 删除告警图标；warning 用警告浅底；primary 用信任蓝浅底 |
| 标题 | 深海军蓝、约 16px、字重 650 |
| 说明 | slate 正文、约 13px、行高 1.6；写清对象名与后果 |
| 按钮 | 取消 = text；确认 = flat 实心（danger 红 / warning 橙 / primary 蓝），**28px 高**（相对旧确认钮再收紧），带轻阴影 |
| 动效 | 弹层自下轻微上浮 + 缩放入场（220ms）；图标区短缩放入场；尊重 `prefers-reduced-motion` |
| 文案 | 标题用「确认××？」，确认按钮用「确认删除 / 确认标记」等明确动作，不用模糊的「确定」 |

变体：

- `danger`：删除、不可恢复破坏
- `warning`：标记异常、需留意但非永久销毁
- `primary`：启用等正向确认

### 5.4 请求、加载与异常

| 状态 | 呈现规则 |
| --- | --- |
| 加载 | 模块顶部细进度条或按钮加载态，不覆盖整页 |
| 网络异常 | 任务区域内紧凑提示 + "重试"，不误写为权限问题 |
| 认证失败 | "账号或密码错误，请重新输入"，不透露账号是否存在 |
| 无权限 | 仅真实权限边界触发，提供返回合适入口 |
| 成功 | 短暂提示，不改变主区域宽度、不造成页面跳动 |

## 6. Vuetify 组件映射

| 场景 | 组件与约束 |
| --- | --- |
| 主操作 | `v-btn`，信任蓝、**38px（认证页）/ 30px（工作区）**（相对旧规范整体 −10px）、6px 圆角、无渐变；hover 加深为 `#0E4FD1` |
| 次操作 | `v-btn variant="outlined"`，边框 `#D6E0FF` 级浅蓝、文字信任蓝 |
| 输入与搜索 | `v-text-field` `outlined` `density="compact"`、6px 圆角、静态边框 `#E6EBF1`、focus 信任蓝 + 焦点环 |
| 下拉筛选 / 表单选择 | `v-select` `outlined` `density="compact"`，字段约 34px；选项列表 `os-select-menu`（行高 32px），见 §3.4 |
| 入口切换 | 语义化 `role="tablist"`，选中项蓝字 + 2px 下划线 |
| 状态提示 | `v-alert` `density="compact"`、10px 圆角、语义浅底色 |
| 弹窗 | `v-dialog`，12px 圆角、Level 3 阴影 |
| 二次确认 | 必须用 `OsConfirmDialog`，禁止 `window.confirm` |
| 记录容器 | `article`/`v-sheet`，10px 圆角、1px 边框 + Level 1 阴影 |

全局主题：`background: #F6F9FC`、`surface: #FFFFFF`、`primary: #155EEF`、`defaults` 圆角 6px。全局覆盖 Vuetify 默认的单层灰阴影为蓝调层叠阴影。

## 7. 无障碍与响应式

- 每个输入框均有持久可见标签；仅图标按钮必须提供中文 `aria-label`。
- Tab 顺序与视觉顺序一致；焦点使用信任蓝 2px 外圈。
- 常规文字对比度不低于 4.5:1；状态信息不只依赖颜色。
- 手机端常用操作和图标按钮命中区域不小于 `44×44px`，视觉图标可保持克制尺寸。
- 在 `390×844`、`768×1024`、`1440×900` 视口验证：首屏应看到页面名称、关键输入或搜索入口、主操作；无横向滚动。
- `390px`：保险箱首屏保留标题、新增、搜索与筛选入口，完整筛选使用全屏任务层；后台表格转为摘要卡，统计使用 `2×2`。
- `768px`：汉堡按钮打开真实临时导航；保险箱不显示冗余底栏；后台表格在局部滚动区固定标识列与操作列。
- `1440px`：保留固定侧栏、同层工具区和完整数据表，顶栏可吸顶但不得遮挡内容。

## 8. 禁止项

- 不使用假账号、假记录、假统计填充页面。
- 不使用全大写英文副标题、`//` 伪代码文案、Unicode 字符代替图标、安全题材空泛口号。
- 不使用单层灰黑阴影、纯黑标题、大圆角胶囊卡片、渐变按钮、玻璃拟态。
- 不把未实现能力设计成可点击控件；不让管理员入口与个人登录权限边界含混。
