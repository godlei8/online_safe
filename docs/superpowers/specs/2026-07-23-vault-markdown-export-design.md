# 账密 Markdown 导出设计

日期：2026-07-23  
状态：已确认，按方案 A 实现

## 目标

支持用户将保险箱账密导出为 Markdown 文件，便于本地备份与迁移。

## 范围

| 能力 | 说明 |
| --- | --- |
| 批量导出 | 导出**当前列表**（搜索/筛选/排序后可见的记录） |
| 单独导出 | 在记录详情导出当前一条 |
| 格式 | Markdown（`.md`） |
| 内容 | **明文**（含密码等敏感字段真实值） |
| 实现 | **纯前端**：用内存中已解密的 `VaultItemPayload` 生成并下载，不新增后端接口 |

## 交互

1. 列表页标题区、「新增记录」旁增加次操作「导出当前」；当前列表 0 条时禁用。
2. 详情页工具栏增加「导出」。
3. 点击后弹出 `OsConfirmDialog`（`warning`），说明将下载含明文密码的 Markdown；确认后下载。
4. 成功 toast「已导出」；失败 toast 错误信息；**绝不在 toast/日志中回显字段值**。

## Markdown 结构

- 文档头：标题、导出时间、条数、明文警告
- 每条记录：`## 名称` + 平台/渠道/网址/状态/有效期/备注 + `### 字段` 表格（按 `order`，明文）
- 多条之间用 `---` 分隔

## 文件名

- 批量：`online-safe-vault-YYYYMMDD-HHmmss.md`
- 单条：`online-safe-{记录名安全化}-YYYYMMDD-HHmmss.md`

## 非目标

- 后端生成/审计导出
- 管理员导出用户账密
- 剪贴板替代下载
- 导出私人/系统模板本身

## 安全

- 确认文案明确「含明文密码，请妥善保管」
- 客户端下载后由用户自行保管文件
- 不写服务端日志、不写入控制台明文
