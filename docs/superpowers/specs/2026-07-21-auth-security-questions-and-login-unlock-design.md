# 密保重置与登录即开信封设计

> 状态：已确认（2026-07-21 更新：移除恢复密钥重包装）
> 日期：2026-07-21
> 关联：`CURSOR.md`、`在线账密保险箱-产品需求文档-v1.0.md`、`在线账密保险箱-技术选型与架构设计-v1.0.md`、`2026-07-21-vault-core-design.md`

## 1. 产品决策（覆盖旧「主密码 / 解锁 / 锁定 / 恢复密钥重包装」）

1. **忘记密码**：通过密保问题重置**网站登录密码**（最少 1、最多 3 题；注册时设置；系统内置题或自定义）。
2. **删除保险箱「锁定」概念**：无锁定按钮、无自动锁定、无「须再输主密码才能用」的门禁；**登录成功即可使用保险箱**。
3. **加密模型（登录密码单信封）**：
   - 用**登录密码**在客户端 Argon2id 派生 KEK，包装 DEK（替代原「主密码」）。
   - DB 列名可仍为 `wrapped_dek_master*`，语义为 login-password wrap。
   - `wrapped_dek_recovery*` 列保留兼容（初始化时写入随机包装后立即丢弃密钥）；**产品不再生成/展示恢复密钥**。
   - 密保答案**绝不**用于解包 DEK；答案只存哈希。
   - 登录时：前端用用户刚输入的登录密码解包 DEK 并放入内存；登出时清除 DEK。
   - 删除 `/vault/unlock` 门禁与「锁定保险箱」；`/vault/setup` 为「首次初始化信封」。
   - 密保重置登录密码后：服务端清除 `vault_key_bundle` + `vault_item` + `private_template`；登录后走 setup 重建空保险箱。**无 `/vault/rewrap` 流程**。

## 2. 非目标（本轮明确不做）

- 短信 / 邮箱重置登录密码
- 自动锁定超时与锁定按钮
- 单独的「保险箱主密码」产品概念与解锁页品牌
- 恢复密钥展示与重包装页

## 3. 刷新页面与会话恢复

- Session Cookie 仍在，但内存 DEK 丢失时：在保险箱布局内弹出轻量「确认登录密码以继续」，**不**称为解锁保险箱，也无 `/vault/unlock` 路由品牌。
- 优先路径：登录页登录成功后自动解包；用户无感知二次步骤。

## 4. 数据与 API

### 4.1 `user_security_question`（Flyway V9）

| 列 | 说明 |
| --- | --- |
| `owner_id` | 用户 |
| `question_type` | `BUILTIN` / `CUSTOM` |
| `question_code` / `question_text` | 内置编码或自定义文案 |
| `answer_hash` | 规范化后哈希 |
| `sort_order` | 0–2 |

内置题库为代码常量，不落库。

### 4.2 认证 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | 增加 `securityQuestions`（1–3） |
| GET | `/api/auth/security-questions/builtins` | 内置题列表 |
| POST | `/api/auth/password-reset/lookup` | 取回问题（不暴露是否存在用统一文案） |
| POST | `/api/auth/password-reset/confirm` | 校验答案 → 设新登录密码 → 清除保险箱数据 → 吊销 session |
| PATCH | `/api/v1/vault/key-bundle` | 保留兼容，产品前端不再调用 |

## 5. 前端路由与文案

| 路径 | 用途 |
| --- | --- |
| `/register` | 三步：账号 → 登录密码 → 密保 |
| `/forgot-password` | 忘记登录密码；成功页/登录提示「需重新初始化保险箱」 |
| `/vault/setup` | 初始化信封（非设置主密码；不展示恢复密钥） |
| `/vault/rewrap` | 重定向到 `/vault`（已废弃） |
| `/vault/unlock` | 重定向到 `/vault`（删除解锁流程） |

侧栏与顶栏**无锁定**、**无恢复密钥重包装**入口。

## 6. 验收

1. 注册必须设置 1–3 道密保；忘记密码可重置登录密码并吊销会话，且保险箱数据被清除。
2. 登录成功后可直接查看账密明文（已初始化时），用户无需再走「解锁」步骤。
3. 未初始化则进入初始化；初始化后直接进入保险箱，不展示恢复密钥。
4. 密保重置后提示需重新初始化；不做短信/邮箱重置；无重包装页。
